# 封面设计

在分发台进入“封面设计”，查看模板、真实示例与设计规则，复制调用要求，或选定内容后加入制作方案并保存。现有图片与任务状态保持独立。

## Agent 读取

- MCP `desk_cover_templates`：规范全文、设计流程、模板列表。
- MCP `desk_cover_template`，参数 `template_id`：模板版本、示例、调用要求与规范。
- 本机 HTTP `GET /static/cover-design/catalog.json`：同一份机器可读数据。
- `GET /static/cover-design/SKILL.md`：video-cover-design 规范快照。数据包含原始来源与 SHA256，更新规范时同步刷新。
- 保存内容的模板选择沿用 `GET/PUT /api/packages/{id}/creative`，`cover_id` 为模板 ID，带当前 `revision` 防止覆盖其他人的选择。

当前模板：`COVER-PAPER-BLUE@1.0`（成熟纸感黑蓝大字）及 `COVER-WARM-SONGTI@1.0`（暖白蓝色宋体观点）。

## 加入模板

向 static/cover-design/catalog.json 的 templates 添加唯一 ID、名称、版本、适用范围、规则、实际预览、多个构图示例和 agent_request。图片保存于 examples。再运行 scripts/sync_creative_library.py 合并进入制作方案选择库。修改已有风格时更新版本，保留旧参考资产；现有内容不会自动换图。

模板约束字体、色彩、质感和标题层级，实际主体与构图按每条内容原创。模板的风格确认不代表成片或封面的逐张批准，也不授权平台发布。
