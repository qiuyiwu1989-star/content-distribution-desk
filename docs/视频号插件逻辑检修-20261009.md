# 视频号插件 0.7.8 逻辑检修

日期：2026-10-09。范围：本机插件代码、模拟平台控件、后台消息、发布记录API和版本归档。没有操作真实视频号网站。

## 已修复

1. 视频标注第一次选中后文字改变，第二次找不到占位文字：识别已选控件，重复执行不点击；点击后选择未保留则返回失败。
2. 部分frame扫描失败而其他frame找到候选时继续执行：前端预检和后台操作入口均拒绝不完整扫描。
3. 视频上传连续触发input和change导致控件可能重建：只发送一次change。新增测试保证只有一个事件，已有视频或已选文件不触发上传，素材传输失败不触发上传。
4. 自动标注补充暂停和页面/账号检查；单独选项入口补充关联检查，并解除与封面人工核对的无关依赖。

## 验证边界

模拟控件和本地逻辑通过不等于真实平台上传通过。平台裁切预览为canvas或不可核实地址时仍需实际核对封面；定时取决于平台日期控件，应用和分类尚未实现通用自动填写。公开发布仍由用户在平台执行，记录区分观察与人工确认。
