## 使用

先保存平台及分发台当前编辑，重新打开分发台，再在 Chrome 扩展管理页重新加载插件，最后刷新已保存的视频号页面。浮窗应显示 0.7.0。最低 Chrome 106；新增 storage 和 alarms 权限，只用于本机进度和观察记录补传，未增加 debugger 或系统鼠标权限。

1. 选择本条内容，点“自动准备本条”；页面已有本条视频时使用对应接管入口。
2. 面板显示实际步骤，可暂停、停止；当前已经发出的操作会先返回，后续步骤不再派发。
3. 视频上传响应超时也保留尝试记录。继续只检查已有视频，不再次上传；页面必须恰有一个待处理视频。
4. 封面预览失败时暂停，保留“补上传封面”和“下载本条封面”。平台裁切确认后仍需核对最终缩略图；人工核对后继续，保留本次视频和已核对封面。

6. 准备完成后仍需人工核对并单独保存草稿；本版不执行公开发表，也未实现草稿列表重新打开回查。

## 恢复与记录

- 执行进度存于扩展本机存储。刷新后重新选择该条内容可恢复进度，不会自动执行；跨文档继续必须确认当前视频归属。任务版本、素材、排期或合集不一致时不复用旧执行记录。

# 分发台 · 视频号辅助提交扩展

## 安装

1. 解压插件文件夹，打开 Chrome 的 `chrome://extensions`。
2. 开启开发者模式，选择“加载已解压的扩展程序”，选择包含 manifest.json 的 channels-assistant 目录。
3. 保持本机分发台 http://127.0.0.1:4318 运行。
4. 使用你已经登录“邱懿武GPT”的 Chrome，进入视频号“发表视频”页面。安装后刷新该页面。
5. 点击浏览器扩展图标“分发台 · 视频号辅助提交”，选择任务。先核对无重复草稿／作品，再点准备。

## 单条使用

在页面辅助面板确认当前账号，点“上传视频并填写”。扩展会读取任务关联的视频，填写描述、短标题、话题文本和个人观点标注。第一版自动传输视频上限64MB；超出时需要手动上传，不会压缩或改源文件。

当前采用页面元素和可见文字定位，遇到入口不唯一或无法回读时暂停；不要连续重复点击。视频上传由平台完成，面板不声称已上传成功。

封面：面板显示任务封面预览。请在平台打开封面上传编辑器，然后点击面板“填入所选封面”；上传框不唯一时手动选图，裁切与确认由你完成。横版封面和合集第一版手动设置。

话题：第一版将已有话题作为描述文本写入，不保证平台识别为结构化话题；保存前请核对并用平台话题入口调整。

确认上传完成、账号、文案、封面、话题和个人观点正确后，点“保存草稿一次”。平台按钮禁用或不唯一就停止；提交后必须在草稿列表重新打开核对，扩展不自动标记保存成功，也不自动回填分发台。

公开发布：由你在平台点击“发表”，此扩展没有发表或定时提交操作。需要平台原生定时可手工设置，第一版尚未自动填写。

上传进度、取消上传和转码提示未结束时继续等待，不把本地视频预览当作上传完成。完成后才进入封面编辑。批次合集在面板内保存，默认AI与组织，空值表示不选择，不更改平台既有合集；不创建新合集。用户选择声明原创后，自动处理可唯一识别的原创条款弹窗：同意复选框、声明原创按钮、弹窗关闭和主复选框回读。默认模块调用不接受条款，只有面板授权参数启用。位置暂不自动更改。
